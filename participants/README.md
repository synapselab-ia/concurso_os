# Participants

Este diretório contém apenas identidade operacional mínima e enrollments.

O repositório é público. Não registrar documentos, contatos, endereço, credenciais, saúde, dados financeiros ou qualquer dado pessoal sem necessidade estrita e decisão explícita.

IDs são estáveis e neutros (`p001`, `p002`, ...). O alias público pode existir para facilitar operação, mas não é usado como chave técnica.
