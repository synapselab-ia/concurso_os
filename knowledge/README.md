# Knowledge

Conhecimento reutilizável entre concursos vive aqui quando puder ser modelado independentemente de um edital específico.

O concurso aponta para competências; não é proprietário delas. Assim, evidência de uma competência pode ser reaproveitada com cautela em outro concurso, enquanto habilidades específicas de banca continuam separadas.

Convenção inicial de ID: namespace estável e legível, por exemplo `LAW.CP.313A.SPECIFIC_INTENT`.
